## 实现

- 按分配展示已交卷记录，筛选姓名/编号/工号、人员类型、部门、岗位、场景、批次、考核、结果、交卷时间和最终分数；支持全部、已完成、待阅卷。
- 成绩详情仅展示成绩及终审元数据，不授予试题答案或阅卷权限。待阅卷主观分、最终分、是否通过留空。
- 导出确认展示已应用筛选、记录数量和 18 列；导出全部页，最多 10000 条。下载时重新验证权限及最新成绩；文本不作为公式，编号保留前导零，冻结表头并带筛选。
- 列表、详情、选项、预览与下载共同执行数据库中当前账号的本人/部门/下级/全部范围。不接受客户端 userId，试卷与分配、人员、模板必须一致。
- 旧成绩汇总补回人工阅卷完成记录，并修复零分上限、姓名包含匹配及试卷关联校验。
