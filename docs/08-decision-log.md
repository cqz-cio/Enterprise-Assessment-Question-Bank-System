## 2. 建议默认值

### R-001 考核码使用规则

- 建议：考核码绑定一个人和一条考核分配；首次使用后仍允许在未交卷、未过期时恢复；交卷或过期后失效。
- 理由：如果首次打开立即失效，刷新、断网或浏览器崩溃会让候选人无法恢复。

### R-002 多选题评分

- 建议：V1 采用完全匹配得满分，否则 0 分。
- 理由：与当前底座一致，规则简单且争议少。

### R-003 题目删除

- 建议：优先停用或逻辑删除，不物理删除已被试卷引用的数据。

### R-004 选项随机

- 建议：新考核模板默认开启，判断题不随机“正确/错误”的业务含义，但可保持固定显示顺序。
